# Steam 游戏库收藏集分类 · 使用说明

这是一个交给 AI 助手（agent）执行的任务包：它会自动抓取你的 Steam 游戏列表、
帮你设计一套收藏集分类、逐款联网核实每个游戏的真实玩法，最后把收藏集写回你的
Steam 客户端。你只需要回答几个问题、做几次确认。

## 快速开始

1. **获取任务包**（任选其一）：
   - `git clone <仓库地址>` 后进入 `steam-collection-skill/`
   - 或下载仓库的 zip 并解压
   - ZCode 用户：复制到用户级技能目录即可全局自动触发（目录名必须是
     `steam-collection`，与 SKILL.md 里的 name 一致）：
     `cp -r steam-collection-skill ~/.agents/skills/steam-collection`
     放到 `~/.zcode/skills/steam-collection/` 同样有效且优先级更高，二者任选其一
2. **交给 AI 助手**，例如：
   - 直接对 agent 说：*"阅读 steam-collection-skill/SKILL.md，按里面的流程给我的 Steam 库分类"*
   - ZCode 用户：说 *"/steam-collection 帮我给 Steam 库分类"*
3. 按提示填写 `scripts/local_config.json`（从 `local_config.template.json` 复制），
   或者在对话里把信息告诉 agent 让它代填。
4. 剩下的交给 agent。**每个步骤完成后它都会停下来向你汇报并等你确认**，你随时可以
   提要求、纠错或叫停。

## 你需要准备什么

| 项目 | 是否必需 | 说明 |
|---|---|---|
| SteamID 或社区主页链接 | 必需其一 | Steam 客户端左上角菜单→账户→账户详情可见；社区链接形如 `steamcommunity.com/id/自定义名` |
| 本机装有 Steam 客户端 | 写入时必需 | 最后一步要把收藏集写进本机 Steam |
| Python 3 + requests | 跑脚本必需 | agent 会检查；`--login` 功能另需 `pip install playwright` |
| 网络代理（可选） | 视地区 | Steam 访问困难时在配置里填代理地址 |
| 游戏详情隐私为公开 | 可选 | 不公开也能跑（用浏览器登录方式），公开后可用更简单的抓取路径 |

## 四个步骤（你会看到什么）

| 步骤 | agent 做什么 | 需要你做什么 |
|---|---|---|
| ① 抓取游戏列表 | 从 Steam 获取你的全部游戏；需要凭据时可能弹出浏览器窗口请你登录 | 看一眼列表数量对不对，确认 |
| ② 分类体系 + 预分类 | 给你一套收藏集类目提案（你可以自己定，也可以让它按你的库自动设计），然后初步分类 | 确认类目合不合心意、要增删哪些 |
| ③ 联网逐款复核（推荐） | 派出多个 AI 子代理，逐款搜索核实游戏的真实玩法，修正初步分类的错误 | 选择投入多少时间/预算（影响速度与用量），确认修正报告 |
| ④ 写入 Steam | 生成收藏集并写回 Steam 客户端 | **完全退出 Steam**；明确回复"确认写入" |

全部完成后启动 Steam，在库左上角的"筛选器"里就能看到你的收藏集。

## 分类策略：你可以选（让结果更合你意）

agent 会在开工前一次问清下面的选项（详见 `references/options.md`）：

| 你想怎样 | 选项 |
|---|---|
| **精细度** | 精简（每款 1 个主类型）· 标准（1 主 + ≤2 次，推荐）· 宽松（多选不限） |
| **属性维度** | 开（多人合作、VR、手柄…单独成集，不混进"类型"）· 关 |
| **泛化类收紧** | 开（对"动作/冒险/休闲"这类宽泛类型做准入/排除收紧，减少互相重叠）· 关 |
| **复核深度** | 不复核 · 只查可疑款 · 全量 · 全量双遍交叉（最准，成本翻倍） |
| **预算与并发** | 低 / 中 / 高 |

**厂商维度也会自动细化**：兜底类（"其他/小厂"）里的知名厂商会被**逐个单独成类**（如
`Rockstar`、`Cygames`、`中国厂商`），长尾才留在兜底——所以你能按发行商筛选，而不是一大坨"其他"。

> 一句话：**分类哲学交给你定，执行交给 agent。**

## 日常加了新游戏？（增量模式）

分类做完一轮之后，买了/领了新游戏不需要重跑全流程，对 agent 说
*"我 Steam 库里加了几个新游戏，增量更新一下收藏集"* 即可。agent 会：

1. 刷新游戏列表，找出新增/移除/安装状态变化
2. 只对新增的游戏抓资料、联网分类（问你要新游戏的游玩状态）
3. 向你汇报变化，确认后合并进总表、重新生成收藏集并写入

旧收藏集、已分类的游戏全部原样保留，几分钟就能跑完。

## 常见问题

- **浏览器弹出来让我登录安全吗？** 安全。那是本地 Playwright 驱动的浏览器窗口，
  你在 Steam 官方页面登录，脚本只提取登录态 Cookie 存到你本机的配置文件里，
  不上传给任何第三方。
- **我的账号信息会泄露吗？** 所有凭据只存在 `scripts/local_config.json`（本地），
  不会写进任何报告或产出文件。这个任务包本身不含任何账号信息，分享给朋友也没有负担。
  唯一注意：`local_config.json` 含你的登录凭据，**不要把这个文件发给别人**。
- **已经在别的机器上登录过，Cookie 过期了？** 重新跑一次浏览器登录即可，通常不用重新输密码。
- **后悔了想还原？** 每次写入前都会自动备份两份。退出 Steam 后把备份文件覆盖回去即可，
  agent 会告诉你具体路径。
- **新游戏会打乱原有分类吗？** 不会。增量模式只处理新增/移除的部分，
  已分类的游戏和收藏集原样保留。
- **分类不对怎么办？** 单款不对：直接告诉 agent 游戏名和应属分类，改完重新生成写入；
  整体不满意：回到步骤②调整类目重跑。
- **游戏库很大/预算有限？** 步骤③可以选择只复核重点游戏（常玩的、分类存疑的），
  或降低并发数量慢慢跑，agent 会按你的要求安排。
