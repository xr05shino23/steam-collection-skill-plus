# Steam 游戏库收藏集整理

> 一个交给 AI 助手执行的**技能包**：自动抓取你的 Steam 游戏库，设计一套收藏集分类，
> 逐款联网核实真实玩法，最后把收藏集写回你的 Steam 客户端。
> 你只需要回答几个问题、做几次确认。

---

## 它解决什么问题

Steam 库一旦积累到几百款，"找游戏"就变成翻列表；手动建收藏集又极其枯燥——要一款款判断它属于
什么类型、哪个系列、哪家厂商。本项目把这件事交给 AI：

- **自动抓取**你拥有的全部游戏（含**家庭共享**的）；
- **自动设计**一套多维度的收藏集体系（也可完全自定义）；
- **联网逐款核实**每款游戏的真实玩法（Steam 商店标签泛滥，光看标签会分错）；
- **自动写回** Steam 客户端，打开库就能按收藏集筛选。

## 它是怎么工作的（四步流程）

每一步完成后都会**停下汇报、等你确认**，你随时可以纠错或叫停。

| 步骤 | 做什么 | 你需要做什么 |
|---|---|---|
| **① 抓取游戏列表** | 从 Steam 获取你的全部游戏（含家庭共享）；需要登录时会弹出浏览器让你登录 | 核对数量对不对 |
| **② 设计分类 + 预分类** | 给你一套类目提案（也可完全自定义），再做初步分类 | 确认类目合不合心意 |
| **③ 联网逐款复核** | 派 AI 子代理逐款搜索、核实真实玩法并修正 | 选择投入多少时间/预算，确认修正报告 |
| **④ 生成并写入 Steam** | 生成收藏集并写回 Steam；写前强制确认 | 完全退出 Steam；回复"确认写入" |

分类体系采用 **ABCDE 方法论**（可扩展）：

- **A 状态**：正在玩 / 计划玩 / 长线常驻 / 暂时搁置（仅已安装，互斥）
- **B 系列**：同一 IP 的历代作品（如生化危机、最终幻想）
- **C 类型**：玩法类型（动作 / 角色扮演 / 策略 / 解谜 / 视觉小说 …）
- **D 厂商**：开发商 / 发行商（含中国厂商、知名厂商单独成类）
- **E 其他**：工具 / 软件 / 原声等非游戏内容
- **F 特性**：属性维度（多人合作、VR、手柄支持 …）

## 核心亮点

- **联网核实，不靠标签**：让 AI 逐款搜索真实玩法来修正，准确率远高于纯标签规则。
- **家庭共享也整理**：不只看"你拥有的"，把家庭组共享的库一并纳入。
- **多维分类、自由筛选**：类型 / 系列 / 厂商 / 状态 / 特性各成维度，一款游戏可同时属于多个。
- **类目质量可控**：内置"类目体检"（计算两两类目的重叠），避免"冒险/休闲/合作"这类宽泛类
  互相吸收、收藏集虚胖。
- **厂商维度智能细化**：把"其他厂商"里被埋没的**中国厂商**联网判定后单独成类，
  知名厂商（Rockstar、Cygames 等）逐个独立成类。
- **可选策略档位**：精细度（1 个主类型 / 1主+2次 / 不限）、是否建属性集、复核深度、预算——**你说了算**。
- **长任务不崩**：会话状态自动落盘（`HANDOFF.md`），跑几小时的任务换窗口也能接着干。
- **增量更新**：分类过一次后，新买/新领的游戏只处理新增部分，几分钟跑完。
- **写入安全**：Steam 运行守卫 + **双备份** + 原子写入，且**保护系统"收藏夹/已隐藏"**；随时可回滚。

## 适合谁

- Steam 库里有**几十到上千款**游戏、想整理却懒得手动分的人；
- 喜欢"用 AI Agent 处理重复劳动"的玩家 / 极客；
- 想把自己的分类哲学（按类型？按厂商？按系列？）固化下来的人。

## 你需要准备

| 项目 | 是否必需 | 说明 |
|---|---|---|
| SteamID 或社区主页链接 | 必需其一 | Steam 客户端左上角 账户 → 账户详情 可见 |
| 本机装有 Steam 客户端 | 写入时必需 | 收藏集要写进本机 Steam |
| Python 3 + requests | 跑脚本必需 | agent 会检查；浏览器登录另需 `playwright` |
| 网络代理（可选） | 视地区 | Steam 访问困难时在配置里填代理 |
| 游戏详情设为公开 | 可选 | 公开后抓取更省事；不公开也能用浏览器登录方式 |

## 快速开始

1. 获取任务包：

   ```bash
   git clone https://github.com/xr05shino23/steam-collection-skill-plus
   ```

2. 交给 AI 助手，例如对它说：

   > 阅读 `SKILL.md`，按里面的流程帮我整理 Steam 库的收藏集。

3. 按提示填写 `scripts/local_config.json`（从 `local_config.template.json` 复制），
   或者在对话里把信息告诉 agent 让它代填。
4. 剩下的交给 agent：**每一步它都会汇报并等你确认**。

> 作为技能安装（如 ZCode）：复制到用户级技能目录，目录名须与 `SKILL.md` 里的 `name` 一致：
> `~/.agents/skills/steam-collection`。

## 使用示例

```
你：阅读 SKILL.md，帮我整理 Steam 库的收藏集
AI：（步骤1）抓到 602 款（含家庭共享 271），已安装 8 款 —— 数量对吗？
你：对
AI：（步骤2）类目提案：A 状态 4 / B 系列 58 / C 类型 22 / D 厂商 53 / F 特性 1 —— 可以吗？
你：C 类型太多，"休闲"和"冒险"看看会不会重叠
AI：（体检 + 收紧后）……
AI：（步骤4）将写入 135 个收藏集，请完全退出 Steam —— 回复"确认写入"
你：确认写入
AI：已写入；回滚用备份 xxx.json 覆盖回去即可
```

## 安全与回滚

- 写入前会**自动备份两份**（本机 + 项目目录），退出 Steam 后用任一备份覆盖回目标文件即可还原；
- 写入只替换本工具生成的自建收藏集，**系统"收藏夹 / 已隐藏"原样保留**；
- 凭据（Cookie / API key）只存本地 `scripts/local_config.json`，**绝不写进任何产出或汇报**。

## 常见问题

- **弹浏览器让我登录安全吗？** 安全。那是本地 Playwright 驱动的浏览器，你在 Steam 官方页面登录，
  脚本只把登录态 Cookie 存到本机，不上传任何第三方。
- **会打乱我原有分类吗？** 不会。写入只动本工具生成的收藏集；增量模式只处理新增 / 移除的游戏。
- **分类不对怎么办？** 单款不对：直接告诉 agent 游戏名和应属分类；整体不满意：回到步骤②调整类目。
- **库很大 / 预算有限？** 步骤③可只复核重点游戏（常玩的、分类存疑的），或调低并发慢慢跑。
- **分类哲学能自定义吗？** 可以。步骤②可完全自定义类目，也能选分类精细度、是否建属性集、复核深度等。
